# test-app

A small Node.js command-line quiz application located in the test-app directory. This repository contains the application source, sample data, and supporting files to run the quiz locally.

## Contents

- test-app/: Source code for the quiz application (index.js, package.json, src/)

## Requirements

- Node.js (v12+ recommended)

## Setup

1. Change into the application directory:

   cd test-app

2. Install dependencies:

   npm install

3. Run the app:

   node index.js

## Project Structure

- test-app/
  - index.js - application entry point
  - package.json - npm metadata and scripts
  - data/questions.json - sample quiz questions
  - src/ - helper modules (colors, input, quiz)
